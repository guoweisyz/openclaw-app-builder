## 📝 推广文案

### 标题
**MCP Server Manager - npm for MCP servers**

### 正文
```
刚发布了 MCP Server Manager (mcpm) - 一个让管理 MCP Servers 像安装 npm 包一样简单的 CLI 工具。

✨ 核心功能：
• 搜索和发现 MCP Servers
• 一键安装和配置
• 导出配置到 Claude/Cursor/OpenClaw
• OpenClaw 深度集成

🚀 快速开始：
npm install -g mcp-server-manager
mcpm search postgres
mcpm install @modelcontextprotocol/server-postgres
mcpm openclaw sync

🔗 项目地址：[GitHub 链接]

#MCP #ModelContextProtocol #AI #OpenClaw #CLI
```
