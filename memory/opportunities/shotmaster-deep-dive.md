# 截图即代码工具深度分析

## 一、市场背景

### 现有产品
| 产品 | 定价 | 特点 | 弱点 |
|------|------|------|------|
| **ScreenshotOne** | $9-99/月 | 功能全面，API 稳定 | 国外产品，国内访问慢 |
| **ScreenshotAPI.net** | €5-49/月 | 简单易用 | 功能较简单 |
| **Urlbox** | $19-199/月 | 企业级 | 贵，国内无节点 |
| **Thum.io** | $15-99/月 | 实时截图 | 功能单一 |

### 市场缺口
- **国内 CDN**：国外产品国内访问慢
- **小程序截图**：现有产品不支持微信/支付宝小程序
- **本地化**：符合国内使用习惯（如钉钉/飞书集成）

## 二、核心痛点

### 痛点1：网页截图用于文档/演示
**场景**：
- 技术写文档需要产品截图
- 设计师需要对比不同版本的网页
- 运营需要监控竞品页面变化

**现有方案问题**：
- 手动截图费时
- 长网页需要滚动拼接
- 不同设备尺寸需要分别截图

### 痛点2：自动化测试需要截图对比
**场景**：
- UI 回归测试
- 监控网页异常变化
- 记录用户操作流程

**现有方案问题**：
- Puppeteer/Playwright 配置复杂
- 需要自己搭建截图服务
- 缺乏对比和报告功能

### 痛点3：小程序截图困难
**场景**：
- 小程序开发需要截图用于审核
- 运营需要监控小程序页面
- 测试需要记录小程序 UI

**现有方案问题**：
- 几乎无现成方案
- 需要真机或模拟器
- 无法自动化

---

## 三、解决方案：ShotMaster

### 产品定位
**"开发者的截图助手"** — 简单、快速、支持小程序的截图工具

### 核心功能

#### 1. 基础截图
```bash
# 网页截图
shot https://example.com
shot https://example.com --full-page
shot https://example.com --viewport 1920x1080

# 组件截图
shot https://example.com --selector "#header"
shot https://example.com --selector ".product-card"

# 等待元素出现后截图
shot https://example.com --wait-for "#content-loaded"
```

#### 2. 批量截图
```bash
# 从文件读取 URL 列表
shot --urls urls.txt --output ./screenshots/

# 多设备截图
shot https://example.com --devices mobile,tablet,desktop

# 对比截图（用于回归测试）
shot https://example.com --compare baseline.png --diff diff.png
```

#### 3. 小程序截图（差异化功能）
```bash
# 微信小程序截图
shot --miniapp wechat --appid wx123456 --page pages/index/index

# 支付宝小程序截图
shot --miniapp alipay --appid 20210001111 --page pages/home/home

# 需要开发者工具配合
```

#### 4. 自动化集成
```bash
# GitHub Actions
shot --ci --config shot.config.js

# 生成报告
shot report --format html --output report.html

# 上传图床
shot https://example.com --upload qiniu
shot https://example.com --upload oss
```

#### 5. 云端服务（付费功能）
```bash
# 使用云端 API（无需本地安装浏览器）
shot https://example.com --cloud --key YOUR_API_KEY

# 定时截图
shot https://example.com --schedule "0 9 * * *" --cloud

# 监控变化
shot https://example.com --monitor --alert webhook
```

## 四、技术架构

### 本地版
```
shot CLI (Node.js)
    ├── Puppeteer/Playwright (浏览器控制)
    ├── Image Processing (Sharp)
    ├── Diff Engine (pixelmatch)
    └── Config Manager
```

### 云端版
```
API Gateway
    ├── Screenshot Worker (Puppeteer + Docker)
    ├── Queue (Redis)
    ├── Storage (S3/OSS)
    └── CDN (阿里云/腾讯云)
```

### 技术栈
- **CLI**: Node.js + Commander.js
- **截图**: Puppeteer/Playwright
- **图片处理**: Sharp
- **对比**: pixelmatch
- **云端**: Node.js + Express + Redis
